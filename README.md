# Kaju Soni — From Seed to Story

An interactive scroll story: a cashew named Kaju dives into the soil, grows roots (education) and, chapter by chapter, grows into a tree (career), bears fruit (best work) and says hello (contact).

Plain HTML/CSS/JS with GSAP ScrollTrigger (bundled in `vendor/`). The character and roots are SVG, so everything stays sharp and light.

Run locally: `python3 -m http.server` and open http://localhost:8000
